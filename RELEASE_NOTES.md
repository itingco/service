# v1.4 - PDF Export + Self-Service Analytics Sync

- BI PDF report: KPI, trend/forecast SVG, annual trend, channel intelligence, drivers, strategy actions, customer/product movement, breakdown, risk/opportunity.
- Advisor PDF: product context, facts, diagnosis, trend, market opportunities, cross-sell, strategy experiments, external sources and recent advisor notes.
- Web-triggered 36-month sync, background process, progress polling, status history, stale guard and anti-double-run.
- Uses existing `barryvdh/laravel-dompdf`; no new Composer dependency.
